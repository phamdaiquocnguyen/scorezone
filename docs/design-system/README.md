# ScoreZone Design System

Design system used to maintain visual consistency across ScoreZone's
web interface.

## 1. Color

### Brand Colors

| Token | Hex | Usage |
|---|---|---|
| Primary 700 | `#004AC6` | Main actions, active states |
| Primary 600 | `#2563EB` | Links, hover, secondary emphasis |
| Primary Soft | `#FAF8FF` | Popup and supporting surfaces |
| Accent Soft | `#D5E3FD` | Inactive chips and supporting areas |

### Foundation Colors

| Token | Hex | Usage |
|---|---|---|
| Background | `#F8FBFF` | Main page background |
| Surface | `#FFFFFF` | Cards, header, tables |
| Surface Soft | `#F2F3FF` | Secondary surfaces |
| Border | `#D9E6FF` | Borders and dividers |
| Text Primary | `#1D2B6B` | Headings and important content |
| Text Secondary | `#3357A5` | Metadata and supporting text |

### Semantic Colors

| Token | Hex | Usage |
|---|---|---|
| Danger | `#AE0010` | Errors and critical states |
| Warning Surface | `#FFDDB8` | Warning messages |
| Success | `#16A34A` | Success states |

## 2. Typography

**Font:** Inter

| Level | Weight |
|---|---|
| Hero | Extra Bold |
| Heading | Bold |
| Body | Regular |

Typography follows a clear hierarchy between headings,
body content and metadata.

## 3. UI Elements

The design system defines reusable patterns for:

- Primary / Secondary buttons
- Search fields
- Filter chips
- Competition tabs
- Cards
- Badges
- Status indicators
- Navigation
- Modals and popovers

## 4. Design Principles

### Readability
Light backgrounds and clear text contrast.

### Clear hierarchy
Blue is used to emphasize primary actions and important information.

### Consistent states
Danger, Warning and Success states use consistent semantic colors.

### Accessibility
Color is combined with text, icons and layout rather than being
the only indicator of state.
